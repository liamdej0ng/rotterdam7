# Rotterdam VII

Een Nederlandse open-wereld game in Rotterdam: rijden, missies, een verhaal, de radio, garages en nog veel meer. In het Nederlands, Engels en Duits.

**Downloaden:** https://liamdej0ng.github.io/rotterdam7/ (of via [Releases](https://github.com/liamdej0ng/rotterdam7/releases/latest))

Installeer `Rotterdam-VII-Setup.exe`. Updates komen daarna vanzelf binnen.
