# Rotterdam VII

Een Nederlandse open-wereld game in Rotterdam: rijden, missies, een verhaal, de radio, garages en nog veel meer.

**Downloaden:** https://liamdej0ng.github.io/rotterdam7/

Start `Rotterdam-VII.exe`. Updates komen daarna vanzelf binnen via de launcher.
